# Download and Installation

## System Requirements

- 64-bit processor (x86_64)
- 4GB RAM minimum (8GB recommended)
- 20GB disk space minimum
- Modern graphics card with Wayland support
- Internet connection (optional, for updates and additional software)

## Download

Download the latest Quenva Linux ISO image:

[![Download](download.png)](https://github.com/quenva/quenva-config/releases/latest)

## Installation Methods

### Live USB (Recommended)

1. Download the ISO image
2. Create a bootable USB drive (8GB or larger) using tools like:
   - Rufus (Windows)
   - GNOME Disks (Linux)
   - Etcher (Cross-platform)
3. Boot from the USB drive
4. Try Quenva Linux in live mode or proceed with installation

### Direct Installation

1. Boot from the installation media
2. Select "Install Quenva Linux"
3. Follow the graphical installer
4. Choose your language and keyboard layout
5. Configure your network (optional)
6. Create your user account
7. Set up disk partitioning
8. Wait for installation to complete
9. Restart your system

## First Boot

On first boot, Quenva Linux will:
- Set up your KDE Plasma desktop environment
- Configure hardware and drivers
- Enable system updates
- Show the welcome screen with next steps

## Post-Installation

1. Update your system:
   ```bash
   sudo apt update && sudo apt upgrade
   ```
2. Install additional software through Discover
3. Configure your desktop preferences
4. Set up backups
5. Enable additional repositories if needed
